   - GPIO: SDA=21, SCL=22 (compartilhados com OLED/RTC)

2. BIBLIOTECAS ADICIONADAS
   ✓ LiquidCrystal_PCF8574.h - Controle do LCD via protocolo I2C (com controlador PCF8574)

3. CONFIGURAÇÕES ADICIONADAS
   ✓ LCD_ADDR = 0x27 (endereço I2C do LCD)
   ✓ LCD_COLS = 16, LCD_ROWS = 2
   ✓ LCD_UPDATE_MS = 1000 (atualização a cada 1 segundo, não-bloqueante)

4. VARIÁVEIS GLOBAIS ADICIONADAS
   ✓ descricaoClima - String com descrição textual do clima (JSON da API)
   ✓ simboloClima - Símbolo visual: [Sol], [Nuvem], [Chuva] ou [Frio]
   ✓ ultimaAtualizacaoLCD - Timestamp para controle não-bloqueante

5. FUNÇÕES ADICIONADAS

   a) atualizarSimbolo()
      - Analisa temperatura e descrição do clima
      - Retorna símbolo apropriado:
        * [Sol]   = temperatura > 25°C
        * [Nuvem] = 14°C <= temperatura <= 25°C
        * [Chuva] = descrição contém "chuva", "rain", "chuvisco" ou "drizzle"
        * [Frio]  = temperatura < 14°C
        * [--]    = desconhecido

   b) atualizarLCD()
      - Atualiza display LCD a cada LCD_UPDATE_MS (1 segundo)
      - Controle NÃO-BLOQUEANTE: retorna imediatamente se não passou intervalo
      - Exibe:
        * Linha 1: HH:MM | Temperatura(DHT)
        * Linha 2: IP/AP | Símbolo clima

6. ALTERAÇÕES NA FUNÇÃO pegarClima()
   ✓ Extrai campo "weather[0].description" do JSON da API OpenWeatherMap
   ✓ Armazena em descricaoClima com .toLowerCase() para comparação case-insensitive
   ✓ Detecta chuva automaticamente via string matching

7. SEQUÊNCIA DE BOOT ATUALIZADA

================================================================================
DETALHES TÉCNICOS
================================================================================

PROTOCOLO I2C COMPARTILHADO:
  - OLED SSD1306: 0x3C
  - LCD 16x2: 0x27
  - RTC DS3231: 0x68
  - EEPROM (opcional): 0x50
  - Todos no mesmo barramento: SDA=GPIO21, SCL=GPIO22

FORMATOS DE EXIBIÇÃO NO LCD:

  Linha 1 (16 caracteres):
  ┌─────────────────────┐
  │ HH:MM | TT.TC      │
  │ 14:30 | 23.5C      │  (exemplo)
  └─────────────────────┘

  Linha 2 (16 caracteres):
  ┌─────────────────────┐
  │ IP/AP     [Símbolo]│
  │ .168.1  [Sol]      │  (exemplo - mostra últimos 7 chars do IP)
  └─────────────────────┘

TRATAMENTO NÃO-BLOQUEANTE:
  - Verificação: if (agora - ultimaAtualizacaoLCD < LCD_UPDATE_MS) return;
  - Permite que loop principal continue em ~1000 ciclos antes de atualizar LCD
  - Melhora responsividade do sistema

DETECTAÇÃO DE CHUVA:
  - Via campo "weather[0].description" da API OpenWeatherMap
  - Busca case-insensitive: "chuva", "rain", "chuvisco", "drizzle"
  - Descrição vem em português (lang=pt_br no URL)
