{
  "atual": [
    tempoLoopUs,            // [0] Tempo total do loop em microsegundos

    tempoLeituraBotoesUs,   // [3] Tempo de processamento de botões
    dhtTemperature*10,      // [4] Temperatura DHT × 10 (int)
    tempoAtualizarDisplayUs,// [5] Tempo de update do display
    dhtHumidity*10          // [6] Umidade DHT × 10 (int)
  ],
  "hist": [
    [...], // função 0
    [...], // função 1
    [...], // função 2
    [...], // função 3
    [...], // função 4
    [...], // função 5
    [...], // função 6
  ],
  "pos": perfHistPos,      // Posição atual no ring buffer
  "full": true/false,      // Se buffer completou primeira volta
  ... (campos adicionais: cpu, heap, wifi, ap, etc)
}

PROCESSAMENTO NO FRONTEND (gPerf):
1. Busca JSON de /api/perf
2. Para cada função (f=0 até 6):
   - Reordena ring buffer usando pos e full
   - Define label: "°C" se f===4, "%" se f===6, "us" caso contrário
   - Converte valor atual: divide por 10 se f===4 ou f===6
   - Chama drawChart() com dados ordenados

DESENHO (drawChart):
- Fundo: #0d0d16 (quase preto)
- Grid: 4 linhas horizontais
- Preenchimento: gradiente de cor com 44% e 08% de transparência
- Linha: 2px com shadow de 10px
- Estatísticas: max/min no canto inferior

LOCALIZAÇÃO: relogio3.ino:1878 / relogio6.ino:2657
LÓGICA: IDÊNTICA em ambas

Pseudocódigo:
```
if (millis() - ultimaAmostraPerf >= PERF_SAMPLE_MS) {
  perfHist[0][perfHistPos] = tempoLoopUs;
  perfHist[1][perfHistPos] = tempoPegarClimaUs;
  perfHist[2][perfHistPos] = tempoRtcNowUs;
  perfHist[3][perfHistPos] = tempoLeituraBotoesUs;
  perfHist[4][perfHistPos] = (uint32_t)(isnan(dhtTemperature) ? 0 : dhtTemperature * 10.0f);
  perfHist[5][perfHistPos] = tempoAtualizarDisplayUs;
  perfHist[6][perfHistPos] = (uint32_t)(isnan(dhtHumidity) ? 0 : dhtHumidity * 10.0f);
  
  perfHistPos = (perfHistPos + 1) % PERF_HIST_SIZE;
  if (perfHistPos == 0) perfHistFull = true;
  ultimaAmostraPerf = millis();
}
```

DIFERENÇA DE COMPORTAMENTO:

  - Completa 60 amostras em 5 minutos

relogio6.ino:

  - Completa 288 amostras em 24 horas
  - Dados persistem entre boots (salvos em flash com CRC)

IMPACTO NA WEB:
- Gráficos em relogio6 mostram escala temporal 24 horas vs 5 minutos
